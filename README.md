# THE FOOL QUEST

GitHubへこのフォルダ内のファイルをアップロードし、Cloudflare Pagesへ接続して公開できます。

## 自動表示

- Lv：1980年11月17日を基準に年齢相当のレベルを自動計算
- Day+14：端末の当日から14日後を `mm/dd` で自動表示
- Total：TikTokとCouponの合計
- CSV更新：画面の「あるの」を押し、ポイント履歴CSVを選択
- 目標超過時：`OVER KILL`を表示

TikTokはCSVの「チャージポイント」列を合計して端末内へ保存します。Couponの自動取得は次の連携段階で追加します。
