## Device-check outcome — recorded 2026-11-13

Pixel 10 physical check (user screenshot, 2026-11-13): the forecast title still rendered only 「月末予」 — the code43 −3 size cut did NOT take effect on the physical device, although the emulator gate showed four glyphs. Root cause was established the same day: the width fit normalizes the rendered title to the amount budget while it binds, so the size cut changed nothing on the device; the title's safety margin was only ~0.6dp and pixel-snapped advances overshot it by ~1–3px, wrapping the last glyph off the single-line layout; the instrumentation had never rendered the calendar at device height. The defect is addressed by code44 (PR #64, reserved-fit sizing with a 4dp reserve, reproduced in the gate before fixing); see release-tests/code44/CHECKPOINT.md. The remaining code42 checklist items (in-place retention, settings persistence, offline, restore) remain unreported.
